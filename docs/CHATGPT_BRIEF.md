# GPT 논의용 요약 · v0.2

Super Function Hero는 네 함수의 실제 그래프가 캐릭터의 이동·공격인 게임입니다. 수학 퀴즈나 정답 함수 검사는 없습니다.

현재 구현:

- x 대시, x² 상승, −x² 빠른 하강, sin x 물결.
- 모바일 가로 타이틀·플레이·결과의 동일 크기 프레임과 좌우 2+2 HUD.
- 60초 연속 코스, HP 3, CORE 11개와 연결된 Gate 11개.
- HAZARD는 회피할 파괴 불가 위험물. ENEMY는 놓쳐도 HP를 잃지 않는 보너스.
- 일반 CORE는 실제 공격 경로로 파괴. 충격판/금 간 바닥은 공중 급강하 착지로 활성화.
- 바닥 붕괴 후 실제로 아래 루트에 내려가 4마리 보너스 웨이브, 경사로 복귀.
- 작성된 패턴 블록, 콤보·PERFECT·hit stop·파티클·효과음·140ms 입력 버퍼.

지금은 사용자가 제안한 로드맵의 **v0.2 게임 문법**을 검증하는 단계입니다. v0.3의 2~3분/다중 환경/속도 상승, v0.4 새 함수 Campaign, v0.5 계수 Loadout, v0.6 Endless, 이후 랭킹·PWA는 아직 구현하지 않았습니다.

다음 대화에서는 함수 추가보다 세 오브젝트의 읽기 쉬움, 급강하를 사용하는 이유, Gate 실패의 납득 가능성, 60초 코스의 재도전 재미를 먼저 검토해 주세요. 전체 계획은 ROADMAP.md, 구체적 현재 상태는 NEXT_STEPS.md와 IMPLEMENTATION.md입니다.
