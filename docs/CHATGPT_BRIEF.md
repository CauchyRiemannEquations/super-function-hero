# Super Function Hero — GPT 논의용 요약

## 이 프로젝트는 무엇인가

“수학 함수 그래프가 곧 캐릭터의 액션 기술이 되는 횡스크롤 액션게임.”

플레이어는 오른쪽으로 자동 이동합니다. 적이 다가오면 네 함수 버튼 중 하나를 누릅니다. 캐릭터가 해당 함수의 정규화한 궤적을 실제로 따라 움직이며 공격·회피·이동합니다. 문제를 표시하거나 정답 함수를 고르는 퀴즈 형식은 금지합니다.

옛날 슈퍼액션히어로의 단순한 입력, 즉각적인 액션, 콤보, 짧은 미션의 손맛을 참고했습니다. 캐릭터나 디자인을 복제하지 않았습니다. 현재는 흰 헬멧·코랄 스카프의 단순한 캐릭터와 밝은 도시 옥상입니다.

## 지금 실제로 구현된 것

- `y=x`: 직선 대시.
- `y=x²`: 강하게 치솟는 포물선 어퍼컷.
- `y=-x²`: 공중 내려찍기. 지상에서도 짧은 도약 후 사용 가능.
- `y=sin x`: 1.5주기 물결 이동. 여러 적 연속 공격.
- PC 키보드 1–4, 세로 모드의 카드 버튼. 모바일 가로에서는 왼쪽 `x / sin x`, 오른쪽 `x² / −x²` 인게임 버튼.
- 모바일 가로 플레이 시작 이후 전체 화면에 가까운 CSS 몰입 모드. 랜딩 문구를 숨기고 safe-area와 손가락 시야 보호 적용.
- 마지막 입력 하나만 140ms 기억하는 버퍼와 마지막 8초의 혼합 러시 두 구간.
- 38초 스테이지 하나, HP 3, 실패·클리어·즉시 재시작.
- 실제 이동 좌표에 기반한 그래프 잔상, 충돌, 화면 흔들림, hit stop, knockback, 파티클, 효과음.
- 콤보, PERFECT, WAVE HIT, PARABOLA COMBO, 간단한 점수.
- React / TypeScript / Vite / Canvas. CSS transition으로 캐릭터를 이동시키지 않음.
- 개발 모드에서 FPS, 좌표, 현재 기술, hitbox, 속도, 적 생성, 무적과 즉시 기술 테스트.
- 로그인, 서버, 계정, 랭킹, 상점, 멀티플레이 없음.

단위 테스트 8개와 브라우저 검증 54개 항목을 통과했습니다. 실제 키 입력으로 타격 21회, 최대 21콤보, PERFECT 15회, HP 3 유지 클리어를 확인했습니다. 모바일 가로와 서로 다른 마지막 러시 경로는 터치 에뮬레이션으로 검사했습니다. 실제 기기에서의 손맛·노치·네이티브 fullscreen·성능은 다음 검증 대상입니다.

현재 화면의 임시 브랜드는 CURVE RUN이고, GitHub 프로젝트 이름은 Super Function Hero입니다.

## 가장 최근 사용자 피드백

사용자가 직접 플레이한 뒤 **“재밌는데”**라고 평가했습니다. 이어서 다음 방향을 제안했습니다.

1. 모바일 가로 환경에서 플레이하고 싶다.
2. 현재 화면 아래에 있는 직선 무브 버튼을 인게임 화면에 넣으면 좋겠다.
3. 곧바로 큰 변경을 하기 전에 GPT와 이 방향을 더 이야기하고 싶다.

이후 사용자가 구체적인 모바일 가로 2+2 HUD 구현을 요청하여 적용했습니다. 이번에는 새로운 기능을 늘리기보다 이 버튼 배치와 시야, 짧은 입력 버퍼, 마지막 러시의 플레이 감각을 실제 기기에서 검증하는 단계입니다.

## 먼저 논의할 질문

1. 가로 플레이 중 랜딩 UI를 숨기는 현재 구조가 실제 휴대폰에서 자연스러운가?
2. 왼쪽 전진 기술 두 개, 오른쪽 상하 기술 두 개의 현재 배치가 엄지에 맞는가?
3. 버튼이 앞쪽 적·그래프 잔상·착지 지점을 가리지 않게 어떻게 배치할까?
4. `x² → -x²` 연결과 `sin x` 다중 타격을 한 손/두 손 터치에서 더 쉽게 만들 수 있을까?
5. 현재의 곡선 형태와 스킬 거리가 작은 가로 화면에서도 즉시 읽히는가?
6. 재미를 판단할 가장 작은 사용자 테스트는 무엇일까? 첫 클리어율, 재도전 횟수, 자연스러운 기술 연결을 어떻게 관찰할까?
