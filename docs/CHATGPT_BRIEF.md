# GPT 논의용 요약 · v0.3

Super Function Hero는 수학 퀴즈가 아니라 함수의 실제 그래프가 이동과 공격인 게임입니다.

현재: x 대시, x² 어퍼컷, −x² 급강하, sin x 웨이브. HAZARD는 파괴 불가, ENEMY는 optional, CORE는 Gate를 여는 필수 목표입니다. 강한 공중 급강하만 충격판과 바닥을 깨고 아래 루트로 내려갑니다.

v0.3에서 150초 / 4 환경 / 17 제작 패턴으로 확장했습니다. 중간 메뉴 없이 계속 진행하고 속도는 최대 12%까지 부드럽게 올라갑니다. 블록의 종료 시간과 반응 여유를 보정합니다. 23 CORE / 23 Gate / 4 아래 루트입니다.

사용자가 만든 실제 로고·로봇·드론·CORE·가시·금 간 바닥 PNG를 적용했습니다. 타이틀 배경만 고정 UI를 제거했고, PLAY와 로컬 기록은 실제 값입니다. 모바일 가로 동일 프레임·좌우 2+2와 140ms 단일 입력 버퍼는 유지합니다.

다음 v0.4의 새 함수 Campaign을 고민하기 전에 실제 기기에서 긴 Run의 피로도·반응 시간·역할 인식·재도전 의향을 관찰하세요. 계수·Endless·서버·랭킹은 후속 로드맵이며 현재 기능으로 취급하지 마세요.
