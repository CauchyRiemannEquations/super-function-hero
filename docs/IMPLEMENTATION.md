# Super Function Hero · 구현 안내

함수 그래프가 실제 이동·공격이 되는 38초 횡스크롤 액션 MVP입니다. 로그인이나 서버 없이 동작합니다.

## 실행

Node.js 22.12+ 또는 24를 사용하세요.

```powershell
cd super-function-hero
npm install
npm run dev
```

브라우저에서 터미널에 표시된 주소(기본 `http://localhost:5173`)를 엽니다. 같은 Wi-Fi의 휴대폰에서는 터미널의 Network 주소로 접속할 수 있습니다. 방화벽 설정에 따라 네트워크 접속이 제한될 수 있습니다.

설치 없이 실행하려면 저장소의 **artifacts/PLAY-SUPER-FUNCTION-HERO.html**을 내려받아 브라우저에서 엽니다. 효과음은 플레이 시작 이후 활성화됩니다. 외부 폰트가 로드되지 않아도 기본 폰트로 플레이할 수 있습니다.

## 조작

| 입력 | 함수 | 액션 |
|---|---|---|
| 1 / 첫 번째 버튼 | y = x | 짧게 상승하는 직선 대시 |
| 2 / 두 번째 버튼 | y = x² | 점점 가팔라지는 어퍼컷 |
| 3 / 세 번째 버튼 | y = −x² | 점점 가팔라지는 내려찍기. 지상에서는 짧은 도약 후 발동 |
| 4 / 네 번째 버튼 | y = sin x | 1.5주기의 물결 이동 |
| Enter | | 시작 / 결과 화면에서 재시작 |
| R | | 즉시 처음부터 재시작 |
| Space / Esc | | 일시정지 / 계속 |

모바일은 `pointerdown`에서 바로 발동합니다. 공중에서도 다른 기술로 연결할 수 있습니다. 0.12초의 중복 입력 제한만 있으며 별도 스킬 쿨다운은 없습니다.

## 게임 규칙

- 캐릭터는 오른쪽으로 자동 달립니다. 앞의 배치와 곡선 아이콘을 보고 기술을 선택합니다.
- 적은 종류에 관계없이 실제 궤적과 공격 범위가 닿으면 맞습니다. 정답 함수 검사는 없습니다.
- 적과 장애물의 직접 충돌은 HP 1 감소, 콤보 초기화, 1.1초 피격 무적을 발생시킵니다.
- 적을 놓치면 콤보가 끊깁니다. 적을 놓친 것만으로 HP가 감소하지는 않습니다.
- HP 0은 실패. 살아서 38초를 달리면 클리어입니다.
- 기본 처치 100점, PERFECT 50점 추가. 콤보마다 15% 보너스가 붙고 최대 +180%로 제한됩니다.
- PERFECT는 선택한 궤적이 적 중심에서 28 게임 단위 이내를 지나는 정확한 타격입니다.
- 한 웨이브로 2마리 이상 타격하면 WAVE HIT. 어퍼컷 타격 후 2.4초 이내 내려찍기 타격은 PARABOLA COMBO.
- 로컬 최고 점수만 브라우저에 저장합니다. 계정·외부 랭킹은 없습니다.

## 구현 구조

```text
src/
  App.tsx              HUD, 스킬 입력, 가이드, 결과, 개발 도구
  style.css            반응형 UI와 간단한 피드백 애니메이션
  game/
    engine.ts          120Hz 고정 스텝, 상태, 충돌, 카메라, Canvas 렌더링
    trajectory.ts      정규화 궤적과 이동 구간 충돌 거리 계산
    trajectory.test.ts 궤적·시작점·충돌 회귀 테스트
    stage.ts           38초의 구간과 적·장애물 배치
    audio.ts           Web Audio 기반 짧은 효과음
```

React는 UI를 담당하고 게임 좌표는 엔진에서 관리합니다. `requestAnimationFrame`으로 그리며 1/120초 단위로 시뮬레이션합니다. 이동 구간을 검사하는 충돌 판정이 빠른 대시의 적 관통을 방지합니다. 탭이 숨겨지면 자동 일시정지합니다.

게임의 y축은 아래로 증가합니다. 상승은 `−t²`, 낙하는 `+t²`를 사용합니다. 웨이브는 평행 이동·위상 이동한 사인 곡선 `(1 − cos(3πt))`으로 옥상 아래를 지나가지 않도록 배치했습니다. 기술 종료 이후에는 중력으로 자연스럽게 착지합니다. 이동 궤적을 실제 좌표로 기록하고 약 0.85초 동안 감쇠합니다.

각 적 그룹은 해당 구간 시점의 플레이어 위치를 기준으로 생성합니다. 따라서 기술의 전진 거리 때문에 다음 구간이 미리 소모되지 않습니다. 미니맵 대신 적의 링과 화면 가장자리의 위치 화살표로 앞의 상황을 예고합니다.

## 개발·검증

```powershell
npm run test
npm run build
npm run preview
npm run standalone
```

개발 서버의 왼쪽 아래 **DEV +**에서 FPS, 좌표, 함수, hitbox, 이동 속도, 무적, 적·장애물 생성, 각 기술 테스트를 제공합니다. 기술 테스트는 시작 후 사용할 수 있습니다. 개발 모드에서만 `window.__curveGame`을 노출하며 빌드에서 제거됩니다.

검증 결과: 궤적·충돌 회귀 테스트 4개 및 브라우저 시나리오 21개 통과. 무적 없이 실제 키 입력으로 HP 3칸을 유지하며 클리어했고, 타격 18회 / 최대 콤보 17 / PERFECT 12 / 4,936점을 기록했습니다. 웨이브 다중 타격, 포물선 연계, 충돌에 의한 HP 0과 재시작, 390px 터치 및 320px 레이아웃을 확인했습니다. 최종 콘솔 경고·오류는 없었습니다.

단일 HTML은 `file://`로 직접 열어 시작, 키보드 기술, 일시정지, 재시작, 실제 적 타격을 추가로 확인했습니다. 개발 UI와 개발 엔진 노출도 배포본에서 제거되었습니다. 상세 요약은 `docs/verification.json`, 실제 플레이 캡처는 `docs/images/desktop-action.png`, `docs/images/desktop-clear.png`, `docs/images/mobile-ready.png`에 있습니다.

## MVP에서 관찰할 것

1. 그래프 아이콘만으로 다음 움직임을 예상할 수 있는가?
2. 누르자마자 기술이 나간다고 느끼는가?
3. 웨이브로 여러 적을 맞히고 싶어지는가?
4. 상승 → 하강을 자연스럽게 연결할 수 있는가?
5. 실패 후 바로 한 번 더 달리고 싶어지는가?

다음 후보는 타이밍 연습 모드, 조금 다른 적 배치를 가진 두 번째 짧은 미션, 계수에 따라 기술의 높이·폭이 달라지는 제한적 실험입니다. 먼저 실제 플레이어의 첫 플레이와 재도전 횟수를 관찰하는 것이 우선입니다.

이 MVP는 Chromium 데스크톱 및 모바일 화면·터치 에뮬레이션으로 검증했습니다. 실제 iOS/Android 기기의 프레임률·오디오·전체 화면 동작은 별도 기기 확인이 필요합니다.
