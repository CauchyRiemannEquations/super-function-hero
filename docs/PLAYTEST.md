# Tangent Parkour 플레이 검토

기존 v0.2 저장소를 리팩터링한 Stage 1–5 vertical slice를 Chromium에서 검토했다. 인앱 브라우저의 실제 Space 입력으로 여섯 경로를 완주했고, 별도 Chromium의 실제 터치 이벤트로 같은 경로·저장·회전·fullscreen fallback을 검증했다. 위치를 바꾸거나 가짜 시계로 완주시키지 않았다.

## 게임 감각

짧은 도입 코스와 빠른 재시도가 접선 타이밍을 바꿔 보는 반복 구조를 만든다. 특히 Stage 5에서 높은 지름길은 약 5.73초/코인 5개, 아래 수집 루트는 약 6.96초/코인 9개로 이어져 속도와 수집 사이의 선택이 작동했다. 첫 세 코스는 약 3–5초의 도입으로 설계했고, 후속 콘텐츠의 지속적인 재미까지 검증한 범위는 아니다.

| 검토 기준 | 확인한 동작 |
| --- | --- |
| 게임 자체의 재미 | 점프 한 번으로 길을 건너는 짧은 호흡, 0.5초 재시도, 빠른 루트와 수집 루트 선택을 구현하고 완주했다. 학생들의 실제 재미 평가는 별도다. |
| 탭 타이밍을 고민하는가 | 모든 코스는 무입력으로 실패한다. ±100ms 이내에는 클리어가 가능하며 Perfect 구간은 더 좁아 보상 차이가 난다. |
| 점프 방향이 직관적인가 | Stage 2의 거의 수평 출발, Stage 3의 상승, Stage 4의 하강을 실제 입력으로 확인했다. |
| 접선 영향을 눈으로 느끼는가 | 초기 반투명 가이드와 0.34초 발사 접선, 중력으로 휘어지는 공중 자취가 연결된다. 초기 속도의 기울기도 실제 실행에서 검증했다. |
| 모바일 가로 조작 | 844×390·740×360에서 화면 탭, 최소 HUD, 44px 결과 버튼을 검증했다. 결과 화면은 내부 스크롤 없이 들어간다. |
| 반복할 이유가 있는가 | 스테이지별 Best Time/점수 저장, 코인·점프·Perfect·콤보 결과, Stage 5의 다른 두 경로를 확인했다. |
| 수학이 억지스럽지 않은가 | 게임 중 함수 선택·정답 판정·긴 수식 팝업을 제거했다. 클리어 후 마지막 기울기만 짧게 표시한다. |
| 자취가 정체성인가 | 달리기와 비행의 서로 다른 빛나는 자취, 결과 카메라의 전체 경로, 화면 왼쪽 66%의 YOUR TRACE를 확인했다. 체크포인트까지의 경로는 재시도 후에도 보존한다. |

## 증거와 제한

- `npm test`: 새로운 테스트 39개 통과. 반복 실패의 자취가 100회 재시도에도 누적되지 않는 검사 포함.
- `npm run standalone`: TypeScript/Vite 빌드와 단일 HTML 생성 통과.
- [터치 검증](verification-tangent.json): 여섯 경로, 기록 유지, 작은 가로 화면, 세로 회전, fullscreen 거부 환경. 최종 게임 런타임 오류 없음.
- [오프라인 HTML 검증](verification-standalone.json): 원격 요청을 차단한 상태의 실제 Stage 1 Space 입력. 코인 7/7, 점프 1, MISS 0. 원격 글꼴을 못 불러오면 로컬 글꼴을 사용한다.
- [설정·오디오 회귀](verification-settings.json): 실제 스위치와 키 입력으로 음소거·모션 감소·새로고침 유지·설정 창의 R/Esc 차단을 검증했다. 테스트 브라우저들은 탭을 바꿔도 문서를 visible로 유지해 네이티브 백그라운드 전환의 자동 일시정지는 미검증이다.

실제 iOS/Android 기기의 터치 가림·주소창·노치·방향 잠금·오디오 정책·성능은 테스트하지 않았다. 자동 경로 완주를 학생들의 재미나 학습 효과에 대한 증거로 해석하지 않는다. 보스전과 Stage 6 이후는 이 vertical slice의 구현 범위가 아니다.
