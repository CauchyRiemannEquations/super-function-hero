# v0.2 구현 상태와 다음 검증

모바일 가로에서는 **타이틀부터 결과까지 동일한 100dvw × 100dvh 프레임**입니다. 플레이 직전에만 크기를 바꾸던 ready 예외를 제거했습니다. 타이틀에서 비활성 컨트롤의 레이아웃도 유지하므로 Canvas 배율과 게임 프레임이 시작 때 바뀌지 않습니다.

이름은 UI·브라우저 제목·문서에서 Super Function Hero입니다. 왼쪽 x/sin x, 오른쪽 x²/−x²의 80px 터치 HUD, safe-area, 140ms 단일 입력 버퍼는 유지합니다.

## 현재 게임 문법

HAZARD는 붉은/검은 경고무늬이며 공격으로 파괴되지 않습니다. 닫힌 Gate는 이동 구간 충돌로 전진을 막고, 연결된 CORE가 파괴되면 기계적으로 열립니다.

ENEMY는 녹색·보라색 로봇과 옅은 녹색 타격 링입니다. 놓쳐도 HP가 감소하지 않으며, 점수·콤보 기회를 잃습니다.

CORE는 금색 표적입니다. 공중/지상 일반 CORE는 실제 공격 경로에 닿아야 합니다. IMPACT/CRASH CORE는 공중에서 시작한 강한 급강하의 착지만 받습니다. 약한 지상 급강하를 연타해도 강한 충격으로 승격되지 않습니다.

## 60초 코스

DASH_GATE → UPPER_DIVE → CRASH_ROUTE → WAVE_ALLEY → UPPER_DIVE → CRASH_ROUTE → MIXED_GATE → WAVE_ALLEY.

- 전진 대시로 첫 잠금 해제.
- 상승으로 공중 CORE를 깨고, 천장 전에 급강하해 충격판 활성화.
- 금 간 바닥을 깨면 실제로 아래로 떨어져 4마리 보너스 웨이브.
- 약 5.3초의 아래 루트 이후 경사로로 복귀.
- 최종 혼합 봉쇄와 마지막 물결.

60초에 도달해도 CORE 11개가 남으면 Clear가 아닙니다. 닫힌 문과 위험물에 충돌하면 HP 1 감소, HP 0이면 실패합니다. 진행 중간 메뉴는 없습니다.
