# 모바일 가로 플레이 — 구현 상태와 다음 검증

상태: **좌우 2+2 인게임 HUD와 모바일 가로 몰입 모드 구현 완료.**

## 적용한 UX

- `(orientation: landscape) and (max-height: 540px) and (pointer: coarse)`를 모바일 가로 조건으로 사용합니다.
- 플레이 시작 이후 playing/paused/clear/over에서 header·intro·설명·footer·외부 카드 패널을 숨깁니다.
- arena와 Canvas는 `100dvw × 100dvh`. 전체 화면 API가 없어도 이 CSS 레이아웃으로 플레이합니다.
- 세로로 돌아가면 기존 랜딩과 카드 버튼이 복원됩니다. 플레이 좌표·HP·시간은 유지합니다.
- 나가기 버튼은 타이틀로 돌아가고 예약 입력과 선택적 fullscreen/orientation lock을 해제합니다.
- 세로 플레이 중에는 가로 회전을 권장하는 작은 안내를 표시하지만, 진행을 막지 않습니다.

## 인게임 버튼

```text
┌────────────────── HP / SCORE / TIME / TOOLS ───────────────────┐
│                   캐릭터 · 적 · 실제 그래프 궤적                │
│                   지상 전투가 손가락 영역 위에 위치             │
│                                                               │
│  [ / x ] [ ∿ sin x ]                    [ ∪ x² ] [ ∩ −x² ]     │
└───────────────────────────────────────────────────────────────┘
```

왼쪽은 전진 기술 두 개, 오른쪽은 상하 기술 두 개입니다. 터치 영역은 80×80px, 시각 버튼은 72×72px입니다. 수식과 그래프만 표시하며 기존 기술 색을 유지합니다. `pointerdown`에서 입력하고, 눌림·현재 기술 발광·대기 입력 테두리를 표시합니다.

`env(safe-area-inset-*)`를 HUD와 버튼·결과 화면에 적용합니다. 엔진은 실제 버튼의 상단을 읽고 추가 24px 여백까지 보호합니다. 전투 좌표를 변경하거나 적을 임의로 다른 높이에 생성하지 않고, 렌더링의 균일 배율과 배경 연장으로 하단 손가락 영역을 확보합니다.

## 입력 버퍼

마지막 입력 하나만 140ms 기억합니다. 120ms 중복 입력 제한에 걸린 빠른 연계는 제한이 풀린 첫 프레임에 실행합니다. 현재 기술의 마지막 140ms 안에 다른 기술을 누르면 기존 기술의 마지막 충돌·착지 공격을 완료한 같은 시뮬레이션 스텝에서 다음 기술을 시작합니다.

기술 도중의 일반적인 즉시 연결은 유지합니다. 여러 기술을 줄 세우거나 장시간 저장하지 않습니다. pause·restart·실패·클리어·나가기에 남은 입력을 버립니다. hit stop 동안에는 게임 시간과 함께 입력 유효 시간도 멈춥니다.

## 마지막 러시

튜토리얼 구간 0–29초는 유지했습니다. 마지막 8초는 두 박자로 구성합니다.

- 30초: 낮은 적 한 마리 뒤에 높이가 다른 세 적. 대시→웨이브 또는 늦게 진입하는 한 번의 웨이브 등으로 통과할 수 있습니다.
- 34초: 공중 적과 뒤의 지상 두 적. 상승→하강이 들어갈 전진 거리를 확보했습니다.

적 종류별 정답 기술 제한은 없습니다. 기존의 실제 궤적/충돌과 스플래시 판정만 사용합니다. 하나의 완벽한 공략을 요구하지 않으며, 적을 놓쳐도 살아서 끝까지 달릴 수 있습니다. 전체 길이는 38초입니다.

## 다음으로 실제 기기에서 확인할 것

1. iPhone/Android 브라우저의 주소창 높이 변화와 실제 노치·홈 영역.
2. 한 엄지에서 `x² → −x²` 연결이 자연스럽게 느껴지는지.
3. 작은 가로 화면의 캐릭터·곡선 크기와 실제 손가락에 가려지는 시야.
4. 지원 브라우저의 네이티브 fullscreen·orientation lock 진입/해제.
5. 저사양 기기의 프레임률·오디오 지연·발열.
6. 첫 플레이에서 각 기술을 구분하는지와 재도전 의향.

새 함수, 계수 변경, FLOW, 계정, 서버, 상점, 성장 시스템은 이번 변경에 추가하지 않았습니다.
