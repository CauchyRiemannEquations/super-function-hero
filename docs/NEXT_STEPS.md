# 현재 상태 · v0.3

- 제공 로고와 다섯 오브젝트 PNG 적용. 타이틀 시안은 장면만 분리하고 버튼·기록은 실제 UI로 구성.
- 150초, 4개 환경, 17개의 제작 패턴. 메뉴 없이 계속 진행.
- 기본 속도 최대 12% 증가, 4초 ramp와 3초 색 혼합. 반응 lead 보정.
- CORE 23개, Gate 23개, 아래 루트 4회. 네 함수와 역할 규칙 유지.
- 패턴 사이의 combo grace 12초. 놓친 적·충돌은 combo를 끊음.
- 데스크톱·모바일 모두 가로 전용 게임 프레임. 헤더·소개·외부 조작 카드·설명·푸터 제거. 타이틀/플레이 동일 크기와 좌우 2+2, 입력 버퍼, 단일 HTML 유지.
- 세로에서는 회전 안내만 표시. 엔진 입력·진행도 차단. 플레이 중 회전하면 HP·시간을 보존해 일시정지하고, 가로 복귀 후 직접 재개.

다음은 v0.4 Function Campaign입니다. 먼저 실제 휴대폰에서 긴 Run의 피로도, 세 역할 인식, 가로 시야·손가락 가림, 속도 상승 후 반응 시간, 재도전 의향을 확인하세요. 새 함수/계수/Endless/랭킹은 아직 구현하지 않았습니다.
