# 개발 로드맵

사용자가 제안한 순서를 따릅니다. **함수의 수보다 함수마다 사용할 이유를 먼저 만듭니다.**

## v0.2 — 게임 문법 완성 · 이번 구현

- HAZARD / ENEMY / CORE의 규칙과 외형 분리.
- 파괴할 수 없는 위험물과 실제 전진을 막는 Gate.
- 실제 궤적으로 일반 CORE를 부수면 연결된 문이 열림.
- 공중 급강하로 충격판·금 간 바닥 활성화. 지상 자동 도약은 약한 공격.
- 천장 위험물, 상승 → 급강하가 필요한 배치.
- 바닥 파괴 후 아래 루트의 4마리 보너스 웨이브, 자연스러운 복귀.
- 60초 직접 설계한 연속 코스, 중간 메뉴 없음.
- 모바일 가로 타이틀·플레이 동일 프레임, 이름 Super Function Hero 통일.

새 함수·계수·Endless·서버를 이 버전에 넣지 않습니다. 첫 목표는 대시 → 위험물 회피 → 공중 CORE → 급강하 → 바닥 붕괴 → 아래 루트 → 웨이브 타격의 짧은 시퀀스가 재미있는지 확인하는 것입니다.

## v0.3 — Continuous Run · 다음

- 1 Run 약 2~3분, 3~4개 Section.
- 중간 메뉴 없이 옥상 → 도심 → 공장 → 야간 환경 전환.
- 완만한 속도 상승.
- 직접 설계한 DASH_GATE / UPPER_DIVE / CRASH_ROUTE / WAVE_ALLEY 같은 패턴을 이어 붙임.
- 패턴의 진입·종료 상태와 물리적 통과 가능성을 먼저 검증.

이번에 이름 있는 패턴 블록의 기반만 만들었습니다. 긴 코스·다중 환경·속도 상승은 아직 구현하지 않았습니다.

## v0.4 — Function Campaign

1. Linear: y=x. 이후 기울기로 공격 각도 조정.
2. Quadratic: y=x² / y=−x². 상승·급강하 역할.
3. Exponential / Log: 후반 급상승 ROCKET과 초반 급상승 후 완만한 이동. 서로 다른 개형을 행동으로 체감.
4. Trigonometric: 물결 이동. 나중에 A는 폭, B는 주기에 대응.

각 월드 마지막은 배운 함수를 섞는 Rush/Boss. 퀴즈나 정답 선택으로 만들지 않습니다.

## v0.5 — Coefficient System

첫 구현은 스테이지 전에 WIDE / NORMAL / STEEP 세 단계 Loadout: ½x² / x² / 2x². 플레이는 한 탭 즉시 발동을 유지하고, 계수에 따라 실제 궤적이 바뀌어야 합니다.

그 다음 선택형 Advanced Control: press → 작은 위아래 조절 → release, 예상 궤적 ghost line. 실시간 슬라이더를 기본 조작에 넣지 않습니다. y=a(x−p)²+q와 평행 이동은 훨씬 뒤의 고급 챌린지 후보입니다.

## v0.6 — Endless Run

Campaign에서 이미 배운, 검증된 패턴만 제한적으로 랜덤 연결. 거리·최고 콤보·점수·속도 증가·환경 변화. 불가능한 조합을 만들지 않도록 진입/종료 조건을 검사합니다. Campaign과 별도의 메인 메뉴 콘텐츠가 됩니다.

## v0.7 이후

Daily Challenge, 캐릭터/스킨, 업적, 랭킹, PWA, 앱 배포, 추가 함수. 핵심 Run이 충분히 재미있어지고 재도전 의향이 확인된 뒤 진행합니다.

## 판단 기준

- 함수를 처음 보아도 움직임을 예상하는가?
- 위험물은 피하고, 적은 보너스로 잡고, CORE는 문을 여는 목표로 인식하는가?
- 급강하가 있어야 살아남고 길을 열 수 있다고 느끼는가?
- 끊김 없이 계속 달리고, 실패 후 다시 하고 싶어지는가?
